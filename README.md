## Repository development history

**Initial model (v1):** the course template (five analyst-informed states with disclosed subjective weights plus a 200-step CRR lattice) applied to real LMT inputs. Dividends are a continuous 2.45% yield. Notebook Sections 1–8 are unchanged template code.

**Model improvement (v2):** LMT's three $3.60 dividends before expiration are modelled as dated cash payments with an escrowed-dividend CRR lattice. This raises the put from $48.33 to $49.05 and moves the model value inside the market's bid-ask range. It also adds American-exercise convergence, implied volatility, an analyst-horizon warning with a disclosed alternative, and extra checks (Section 9). It affects the dividend assumption, the CRR value, the early-exercise premium and every Greek.

**Module 5 Greeks extension (v3):** delta, gamma, theta, vega and rho with stated units and per-contract exposure. These are validated against central finite differences, bump-size tests and a closed-form European benchmark, and tested against full repricing in delta-only, delta-gamma and multi-factor approximations. The extension adds Plotly sensitivity charts, a risk-profile interpretation, the integrated decision memo and an AI-use disclosure (Sections 10–16).

The commit history follows the same three stages; see `CHANGELOG.md`.

## Reproduce

```bash
python -m pip install -r requirements.txt
python -m jupyter nbconvert --to notebook --execute valuation_option_lab.ipynb --output executed.ipynb
cd docs && python -m http.server 8000   # open http://localhost:8000 and /greeks.html
```

Changing any CSV value and re-running the notebook regenerates every number on both dashboards. Nothing on the dashboards is typed by hand.
